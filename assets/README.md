Put your own PNG, JPG, WEBP, GIF, or AVIF images here.

Reference them from content.md using local URLs like:

![A descriptive photo](assets/example.webp)

Only referenced files are copied into dist/assets/.
Remote images and executable SVG/HTML/JS assets are intentionally rejected.

`fonts/` holds self-hosted WOFF2 files listed under `fonts.local_faces` in
style.yaml, plus their SIL Open Font License texts. They are published to
dist/assets/fonts/ only while style.yaml references them.
